# Гармония Души и Тела — сайт студии массажа

Одностраничный сайт частной практики во Владивостоке. Один `index.html`, CSS в `<style>`, ванильный JS, локальные шрифты и фотографии. Без сборки, CDN и сервера.

Живая версия: https://fitfuuxdev.github.io/garmonia-dushi-i-tela/

## Состав

- `index.html` — страница целиком;
- `privacy.html` — политика обработки данных (не менялась при редизайне);
- `fonts/` — Prata 400 и Golos Text 400/500, woff2 с unicode-range;
- `img/` — герой, три фото кабинета, карта, OG-картинка;
- `robots.txt`, `sitemap.xml`, `.nojekyll`.

Локально: открыть `index.html` двойным щелчком. Всё работает офлайн.

## Структура

1. Герой: один смысл, один CTA, телефон, факты.
2. Мастер: подход от первого лица, дипломы — в кабинете.
3. Услуги и цены: список из семи практик, 30/60/90 минут.
4. Как проходит визит: четыре шага.
5. Кабинет: три фотографии + лайтбокс.
6. Как найти: адрес, ориентир, парковка, вход, карта 2x.
7. Запись: телефон, Telegram, MAX, оплата, форма с предзаполненным текстом.
8. Вопросы: шесть ответов, включая противопоказания.
9. Подвал: адрес, график, контакты, дисклеймер, политика.

## Фото-бриф

- герой 2400×1350 WebP ≤ 250 КБ, отдельный вертикальный кроп 1200×1600 для мобильных;
- портрет 1200×1500, галерея 1000–1400 px по длинной стороне, WebP ≤ 200 КБ;
- единый тёплый баланс, но с контрастом и глубокими тенями; не обесцвечивать в серый;
- снимать свет и фактуру: лён, масло, полотенца, руки, дверь с табличкой;
- у всех `<img>` ширина/высота и осмысленный `alt`.

Что переснять в первую очередь:

1. Герой: кушетка с льняной простынёй, тёплый боковой свет, руки мастера или деталь — масло, полотенце. Сейчас на герое свечи.
2. Портрет мастера 4:5 в кабинете, спокойный, без постановочной улыбки.
3. Галерея: дверь с табличкой, кушетка, полотенца, масло, руки в работе. Убрать из кадра мягкие игрушки, часы и всё, что читается как салон красоты.
4. Карта: при желании заменить статичную схему на скриншот 2ГИС в 2x, если права позволяют.

## Проверено

- 320, 390, 768, 1024, 1440, 1920 — без горизонтального скролла;
- H1 — две строки на 1200–1920;
- форма: клиентская валидация, ошибки текстом, ссылка `t.me/...?text=...` с готовым сообщением;
- лайтбокс: клавиатура, Escape, клик по фону;
- `prefers-reduced-motion`: движения отключаются;
- контраст текста ≥ 4.5:1, видимые фокус-кольца;
- без внешних запросов: шрифты, фото и карта лежат локально.
